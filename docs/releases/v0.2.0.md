# v0.2.0 — 交付文件库

给 DSH 对话窗加第三个视图：把当前会话的**全部显式交付**（`present`）与**文件产出**
（`write` / `edit`）汇总成一份可检索的文件库 —— 不用再往回翻聊天记录找"刚才那个文件在哪"。

## 安装

```powershell
dsh plugin --profile desktop add github:BlankTasftu/dsh-delivery-library
```

装好后页签从 `对话 | 轨迹` 变成 `对话 | 轨迹 | 交付文件`。宿主会把新的启动图推给
已打开的页面（一般不用手动刷新）；没出现就按一次 F5。

## 这一版有什么

- **两栏清单**：`交付`（present 声明）与 `产出`（成功写出的文件）分开，各自计数
- **点一行**在右侧栏预览该文件；拿不到右栏时自动退化成"复制路径"，点击不会没反应
- **搜索**同时匹配文件名、目录、说明；重复交付合并为一行并带 `×N` 徽标与轮次
- 会话还有更早历史时，底部给 **加载更早**（走 `session.loadOlder()`）

## 数据口径

| 栏位 | 来源 | 判据 |
| --- | --- | --- |
| 交付 | 会话事件 `deliverables/presented` | `present` 工具**成功**执行后由宿主写入 |
| 产出 | 会话事件 `tool/call` + `tool/result` | 只认 `write`、`edit`、完整改写的 `str_replace_editor`，且**结果不是错误** |

读文件、删除、失败或被中断的调用、参数残缺的调用都不进清单；终端命令创建的文件
只在被显式 `present` 时进「交付」。口径与出厂 `ui-deliverables` 的卡片一致。

## 活动边界（只做插件该做的事）

- **纯插件**：不改 DSH 本体，只往 `conversation.view` 座位追加一个**新 id** 的格子
- 宿主半侧是**空实现**：零 `import`、零 `require`、`apply()` 为空
- 浏览器半侧只 `require('react')`：不联网、不写任何存储、不做动态求值、不碰文件
  （文件只拼一个 `dsh-resource://` 地址交给侧栏服务去读）
- 运行时只做三件事：注入一份带 `data-plugin` 标记的 `<style>`、注册一个视图格子、注册两份词典
- 包内没有第三方运行时依赖、没有安装脚本、没有可执行入口

这些不是口头承诺：`test/isolation.test.mjs` 用 10 条静态断言把它钉住，任何"顺手读个
文件/发个请求/改别的插件配置"的改动都会当场失败。

## 测试

零依赖，不需要安装任何东西：

```powershell
node --test "test/*.test.mjs"    # 60/60
```

测试直接执行**要发货的那份 `lib/client.js`**（复刻 DSH 的 `window.__ModuleLoader__.load`
装载契约 + 一个迷你 React 运行时），所以断言的是发货文件本身，不存在源码与产物漂移。

## 请注意：客户端插件能打崩桌面端

客户端插件的 `apply` 里**任何未捕获异常都会让 DSH 桌面端退出** —— 渲染进程的启动审计
会把未达 `active` 的条目汇总成 `web boot: N entry did not activate`，桌面主进程把它当
致命错误处理。

本插件的 `apply` 因此被刻意写成**整体不可抛**：每一步单独兜住，失败只降级、不冒泡，
并把面包屑写进一个渲染为 null 的诊断条目（可只读检查）。

0.1.0 正是踩了这个坑：一个 CSS 选择器多套了一层引号 → `querySelector` 抛
`SyntaxError` → `apply` 抛错 → 桌面端连续两次启动即退出。修复与完整复盘见
[`docs/DESIGN.md` 第 5 节](https://github.com/BlankTasftu/dsh-delivery-library/blob/main/docs/DESIGN.md)，
回归用例见 `test/styles.test.mjs`（带选择器校验的 document 桩）。

## 已知边界

- 清单只覆盖**已载入**的会话事件窗口（更长历史用「加载更早」向前补页）
- 视图是**会话作用域**的；空会话不渲染视图区（与出厂行为一致）
- 预览的是**当前文件**，不是交付那一刻的快照；文件被删后预览会报找不到
- 不提供"在资源管理器中显示"：那需要宿主 desktop 路由与授权坐标，超出本插件范围
- 极端长的会话（几百个产出文件）列表一次性渲染，没有虚拟滚动
